# R52.RU - разработка и переработка сайта

Открытый скилл для ИИ-агентов: полный процесс от исследования сайта и рынка до готового интерактивного прототипа. Подходит маркетологам, предпринимателям и командам разработки.

[Читать удобную веб-версию](https://klima3567-sketch.github.io/r52-public/website-development-skill/) · [Основные инструкции](skills/r52-website-development/SKILL.md) · [MIT](LICENSE)

## Что делает скилл

| Этап | Что выполняет | Что получается |
|---|---|---|
| 1. Аудит сайта | Проверяет предложение, структуру, содержание, путь к обращению, мобильную версию и SEO | Сильные стороны, проблемы с доказательствами, приоритеты и карта сохранения важных страниц |
| 2. Рынок и конкуренты | Изучает прямых конкурентов, альтернативы и полезные ориентиры | Обоснованная выборка и возможности позиционирования |
| 3. Конкурентная таблица | Сравнивает конкретные решения и способы адаптации | Редактируемая таблица: что хорошо, что берем себе, что прорабатываем |
| 4. Аудитория и JTBD | Определяет ситуации выбора, задачи, критерии, барьеры и роли | Основной JTBD и приоритетные пользовательские сценарии |
| 5. Текстовый прототип | Разрабатывает карту сайта, маршруты, готовые тексты и CTA | Главная и приоритетные типы страниц по блокам |
| 6. Интерактивный прототип | Реализует страницы, адаптивность, переходы, меню и состояния форм | Открываемый прототип, исходники и результаты фактических проверок |

Каждое решение связывается с задачей аудитории, выводом аудита или наблюдением из исследования. Этапы содержат критерии готовности и шаблоны результатов.

## Установка

Устанавливать всю папку `skills/r52-website-development` вместе с `references/` и `agents/`. Одного файла `SKILL.md` недостаточно для полной методики.

### Через установщик скиллов в Codex

Передайте Codex команду:

```text
$skill-installer Установи скилл из https://github.com/klima3567-sketch/r52-public/tree/main/website-development-skill/skills/r52-website-development
```

### Вручную в Codex, macOS / Linux

```bash
git clone https://github.com/klima3567-sketch/r52-public.git r52-public-skills
mkdir -p "$HOME/.agents/skills"
cp -R r52-public-skills/website-development-skill/skills/r52-website-development "$HOME/.agents/skills/"
```

Для одного проекта скопируйте папку в `.agents/skills/` внутри этого проекта. В Windows можно скачать репозиторий через GitHub → Code → Download ZIP и перенести ту же папку в `.agents/skills/` в домашней папке пользователя или в проекте.

Расположение локальных скиллов и способы вызова описаны в [официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills). В других ИИ-средах используйте их штатный импорт навыков формата `SKILL.md`.

## Как использовать

После установки вызовите `$r52-website-development` в Codex или выберите установленный скилл через интерфейс своей среды. Передайте ссылку на сайт либо описание нового проекта, географию, приоритетный продукт и бизнес-цель.

### Полная переработка сайта

```text
Используй $r52-website-development для переработки сайта [URL].
Рынок и география: [описание].
Приоритетные услуги: [перечень].
Главная цель: [целевое действие].
Пройди шесть этапов до интерактивного адаптивного прототипа.
```

### Новый сайт

```text
Используй $r52-website-development. Разрабатываем новый сайт, текущего нет.
Компания и продукт: [описание]. География: [регион].
Основная цель: [цель]. Пройди весь применимый процесс.
```

### Отдельный этап или продолжение

```text
Используй $r52-website-development. Аудит и конкурентная таблица уже готовы: [файлы].
Продолжи с аудитории и JTBD, затем подготовь текстовый прототип.
```

Скилл продолжает работу по актуальным материалам. Согласование каждого этапа можно задать в запросе, если это требуется вашему процессу.

## Какие инструменты нужны

- Для исследования - доступ к поиску и страницам сайтов; для визуального аудита и проверки взаимодействий - браузер.
- Для результатов - возможность создавать документы, XLSX/онлайн-таблицы и HTML либо проект в выбранном стеке.
- Аналитика, CRM и рекламные кабинеты используются при наличии разрешенного доступа. Без них выполняется внешний аудит с указанием ограничений.
- Скилл содержит инструкции и шаблоны. Он не включает платные сервисы, API-ключи и готовые подключения; доступные возможности определяются средой запуска.

Если данные или проверка недоступны, это отмечается в результатах. Цены, отзывы, результаты, интервью и аналитика не придумываются. Формы без подключенной отправки честно показывают только локальную проверку данных.
