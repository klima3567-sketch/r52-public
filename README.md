# Открытые материалы R52.RU

Публичный каталог HTML-аудитов и исследований R52.RU.

- Каталог: https://klima3567-sketch.github.io/r52-public/
- Аудит ЖК «Огни Автозавода»: https://klima3567-sketch.github.io/r52-public/ogni-audit/

## Структура

- `index.html` - главная страница каталога.
- `ogni-audit/index.html` - самостоятельный HTML-аудит со встроенными шрифтами и изображениями.
- `.nojekyll` - публикация статических файлов без обработки Jekyll.

## Публикация

GitHub Pages: ветка `main`, папка `/(root)`. Изменения в этой ветке публикуются GitHub Pages.

Для нового материала создайте отдельную папку с понятным постоянным именем и файлом `index.html`, затем добавьте карточку на главную. При обновлении отчёта сохраняйте его путь, чтобы существующие ссылки продолжали работать.

Репозиторий содержит только материалы, разрешённые к публичному показу.
