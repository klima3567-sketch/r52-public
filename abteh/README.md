# АБТЕХ / Абсолют

Сайт: https://klima3567-sketch.github.io/r52-public/abteh/

Автономный HTML с каталогом, карточками продукции, подбором оборудования и технической документацией. Все изображения и PDF включены в `index.html`; `preview.webp` используется для карточки в общем каталоге. Внутренние разделы работают через hash-маршруты.

В HTML установлены `noindex`, `nofollow`, `noarchive` и `nosnippet`, добавлены директивы Googlebot и Yandex. Поисковикам оставлена возможность прочитать метатеги. Публичный репозиторий остается доступным всем.

Публикация идет через действующий GitHub Pages репозитория из `main` / `(root)`.

Формы проверяют заполнение и подготавливают текст запроса. Серверная отправка заявок пока не подключена.
