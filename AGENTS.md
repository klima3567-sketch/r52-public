# Working with this repository

This repository is a public static HTML catalogue for R52.RU. It is deployed with GitHub Pages from main at the repository root.

- Publish only the materials within the user's authorized scope. Do not copy unrelated client documents or internal notes into this public repository.
- Keep existing report paths stable. The marketing audit is at ogni-audit/index.html.
- Preserve the report's content and interactive features when publishing. Publication alone does not authorize rewriting its findings.
- Keep a corresponding card on index.html for each published material.
- Keep pages self-contained or use relative asset paths compatible with the /r52-public/ project base.
- Verify internal links and publication after updates. Do not claim a live deployment before checking it.
- The audit distinguishes initial findings, recommendations, planning scenarios, and later results; preserve these distinctions.
