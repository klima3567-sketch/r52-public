# Карта проверки первого сценария

Заполняется отдельно для каждого варианта. До проведения показа все результаты имеют статус **не проверен**.

## Паспорт

- Дата и часовой пояс: не назначены.
- Клиника / филиал: не определены.
- Вариант: текущий процесс / настройка DentalPRO / связка со Statum / NNOV.
- Версия и подключённые модули: не установлены.
- Исполнитель и наблюдатель: не назначены.
- Тип примеров: учебные / обезличенные.
- Частота обновления, время последней успешной загрузки: не установлены.
- Одноразовая настройка, обучение, поддержка и полная цена: не установлены.

## Карточка одного наблюдаемого случая

- Неперсональный ключ случая и группа наблюдения:
- Дата включения, версия плана и этап:
- Основание отбора и последняя сверка:
- Решение пациента, причина паузы, ограничение контакта:
- Ответственный, срок и выполненное действие:
- Активные минуты; повторный ввод; время сверки:
- Организационный исход, дата и подтверждение:
- Отдельно: запись / явка / услуга / платёж / отмена / возврат:
- Дата окончания одинакового окна наблюдения:
- Неполные данные и внешние изменения:

## Итог сессии

- Подтверждённый разрыв: не установлен.
- Что уже закрывает текущий инструмент: не установлено.
- Полная стоимость выбранного варианта: не рассчитана.
- Решение: не принято.
- Следующий проверяемый шаг, ответственный и срок: не назначены.
- Подтверждение клиники и дата: не получены.
